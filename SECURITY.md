# Security Policy
## Supported Versions
Only the latest release of TimeCodeSecurity receives security updates.

| Version | Supported |
| :--- | :--- |
| 1.0.x | :white_check_mark: |
| < 1.0 | :x: |

## Reporting a Vulnerability
We take the security of TimeCodeSecurity seriously.
If you discover a potential vulnerability, please report it securely:
1. Use the official **[GitHub Private Vulnerability Reporting](https://github.com/kushigaur3103-svg/time-code-security/security/advisories/new)** feature.
2. Alternatively, email details directly to **kushigaur3103@gmail.com**.
Please do NOT open a public GitHub issue for security vulnerabilities. We will respond within 48 hours.
